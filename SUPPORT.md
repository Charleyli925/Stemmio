# Support

Use [Stemmio Releases Issues](https://github.com/Charleyli925/Stemmio-Releases/issues) for reproducible bugs and feature proposals. Include the Stemmio version, macOS version, device architecture, expected behavior, actual behavior and minimal reproduction material.

Remove personal information and confidential HTML before attaching files. Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
