## The visual workspace between your page and your AI agent

Stemmio turns what you point at on a page into an agent-ready local task. Anchor a request to the whole page, a section, specific text, or an insertion point; add comments, images, files, and long-lived project rules; then let Stemmio freeze the exact HTML and every piece of context your AI agent needs.

**Leave a comment on the page, choose and connect Stemmio Agent, Codex, or Qoder in the AI panel, or copy the task to another local agent.** The same frozen task and review flow applies either way; the connected paths do not use the clipboard for the task handoff.

```text
Point and comment in Stemmio
  → freeze exact HTML + targets + attachments + project rules
  → hand off one local task to your AI agent
  → validate and hold the result as a separate candidate
  → review before and after side by side
  → choose what becomes your current HTML
```

## Visual HTML editing without surrendering your source

Stemmio is a local-first visual HTML editor for macOS—a source-preserving alternative to conventional WYSIWYG website editors for real `.html` files. Open a local page, double-click supported text, and edit with the browser’s native caret, selection, paste, and input-method behavior. Stemmio maps that intent back to the exact source range and writes a minimal patch instead of serializing the preview DOM.

For larger or generative changes, Stemmio prepares a complete local task package. Choose and connect Stemmio Agent, Codex, or Qoder in the AI panel, or copy one concise task to another local agent. In either mode the agent reads the frozen HTML and declared context, writes one complete HTML result to the designated output path, and runs the included finalizer. Stemmio validates the result and keeps it separate, then makes the before/after view the primary next step before you choose which version to use.

It is built for people editing landing pages, prototypes, documentation pages, and static pages generated by AI agents or authored by hand—without giving up visual speed or source fidelity.

### Why Stemmio

- **Edit directly on the page.** Double-click safe text, place the caret where you clicked, type with a native-feeling workflow, format supported text, and reorder supported sibling sections.
- **Preserve the HTML you actually own.** Every persistent visual edit becomes a source-level patch limited to the resolved target. Unrelated markup, formatting, and authored structure are not rebuilt from the DOM.
- **Review AI changes on the page, not in a raw diff.** Before and after open side by side; copy, structure, and visual changes are labeled separately, while your original comments remain pinned to their targets.
- **Choose a connected or portable handoff.** Connect Stemmio Agent, Codex, or Qoder in the AI panel; for another filesystem-capable agent, copy the task without changing the review and adoption flow.
- **Bring AI agent changes back as verified versions.** The submitted source is frozen, returned HTML must pass fail-closed checks, and pre-submit files remain available.
- **Detect conflicts instead of overwriting them.** Local writes are serialized and atomic; an unexpected external file change pauses writeback and asks you to resolve it.

### View the changes before they become current

An AI result can look plausible while still hiding a missed detail. Stemmio makes viewing the changes the primary next step: both versions open at the first change, scroll together by default, and keep unchanged context quiet so the differences are easy to scan. You can filter copy, structure, or visual changes; inspect the content map; switch to either page; and reveal the comments that originally asked for the work.

When the result returns, choose **View changes** to compare the before and after pages. If it is right, choose **Adopt changes**; if not, choose **Skip this change** and continue editing. The candidate remains safely preserved either way; viewing the changes never silently replaces your current HTML.

### From a local HTML file to a reviewed version

1. **Open and edit.** Open a real local HTML file. Safe text edits and supported visual adjustments write back automatically through precise source patches.
2. **Comment and hand off.** Mark the exact place that needs a larger change, add context or attachments, then let Stemmio freeze the task and choose a connected Agent in the AI panel or copy the agent-ready handoff.
3. **Review the AI result.** Stemmio checks and preserves the returned HTML, then shows before and after side by side with each kind of change labeled on the page.
4. **Choose what becomes current.** View the changes, then adopt them when they are right or skip this change and keep working. Neither side is silently overwritten.

### Source-first by design

```text
Authored HTML
  → native DOM / Selection / IME intent
  → SourceIndex + TargetResolver
  → minimal SourcePatch
  → hash-checked atomic file write
```

The current HTML bytes are authoritative. Preview DOM is disposable and is never serialized back as the persistence source. Stemmio is not a low-code page builder, and unsafe or ambiguous edits stop instead of guessing.

- macOS 12 or later

That telemetry does not send HTML, comments, attachments, filenames, paths, clipboard contents, Mac serial numbers, or raw errors; user-authorized Qoder/Agent processing is a separate third-party data path. ## 连接页面与 AI Agent 的可视化工作台

源页会把你在页面上指出的位置，变成 AI Agent 可以直接执行的本地任务。你可以把要求锚定到整个页面、模块、具体文字或插入位置，补充评论、图片、文件和项目长期规则；源页负责冻结准确的 HTML，以及 AI Agent 完成任务所需的全部上下文。

**在 AI 面板选择并连接源页 Agent、Codex 或 Qoder；需要其他本地 Agent 时，可以复制任务。** 无论选择哪种方式，源页都会冻结同一份任务并沿用相同的查看修改与采用流程。

```text
在源页中指出位置并写下要求
  → 冻结准确 HTML + 目标 + 附件 + 项目规则
  → 把一项本地任务交给你的 AI Agent
  → 校验结果并独立保留为候选版本
  → 并排审阅修改前与 AI 修改后
  → 由你决定哪一版成为当前 HTML
```

## 让真实 HTML 始终掌握控制权的可视化编辑器

源页是一款面向 macOS 的本地优先可视化 HTML 编辑器，也是一种不会把预览 DOM 重新序列化回源码的所见即所得编辑方式。打开真实的本地 `.html` 文件，双击安全可编辑的文字，即可沿用熟悉的光标、选区、粘贴和中文输入法体验。源页会把你的操作精确映射回源码，只修改对应范围。

遇到生成内容、跨区域调整或需要更多判断的修改，源页会准备完整的本地任务包。你可以在 AI 面板连接源页 Agent、Codex 或 Qoder，也可以只复制一条简洁任务交给其他本地 Agent。AI Agent 读取冻结 HTML 和声明过的上下文，把一份完整 HTML 写入指定输出位置并执行随附的最终化命令；源页校验后先把结果独立保留，再把修改前后并排展示，让你直接对照真实页面，决定最后使用哪一版。

它适合修改由 AI Agent 生成的落地页、原型、文档页、静态页面和手写 HTML：既获得可视化网页编辑的直观速度，也保留本地 HTML 编辑器应有的源码可信度。

### 为什么选择源页

- **直接在真实页面上修改。** 双击安全文字，光标落在点击位置；自然输入、选择和粘贴，并可调整受支持的文字样式与同级模块顺序。
- **只改你明确选择的范围。** 每次持久化编辑都是源码级局部 Patch，不会用预览 DOM 重建整份文件，也不会顺带改乱无关结构和格式。
- **在页面上审阅 AI 修改，而不是硬看代码 Diff。** 修改前与 AI 修改后并排呈现，精确文字变化与元素新增/删除分别标出；你原来写下的评论仍停在对应位置。
- **选择连接或通用复制。** 在 AI 面板连接源页 Agent、Codex 或 Qoder；其他具备文件能力的 AI Agent 继续通过复制任务使用，后续查看和采用流程不变。
- **把 AI Agent 结果作为经过校验的新版本带回来。** 提交内容先冻结，返回结果必须通过完整校验，提交前文件继续保留。
- **遇到冲突就停止，而不是覆盖。** 本地写回串行且原子；发现文件被其他程序修改时会暂停写入，等待你明确处理。

### 查看修改，再决定是否采用

AI 结果看起来合理，也可能藏着遗漏。源页把“查看修改”放在结果返回后的首要位置：默认从第一处变化开始，修改前后同步滚动，未改区域降低存在感，让真正需要判断的内容更醒目。你可以在“全部 / 文字 / 元素”之间筛选，切换单页，也可以回看当初提出要求的评论。位置、样式、排版和运行态视觉差异不进入本版查看范围。

结果回来后，点击“查看修改”进入修改前后对照；确认满意后选择“采用修改”，不满意就选择“不用这次”并继续编辑。无论如何，AI 候选都安全保留，查看修改本身不会静默替换当前 HTML。

### 从本地 HTML 到经过审阅的新版本

1. **打开并直接修改。** 打开真实本地 HTML；安全文字与受支持的视觉调整会通过精准源码 Patch 自动写回。
2. **评论并交给 AI Agent。** 标出需要较大修改的准确位置，补充说明或附件，由源页冻结本轮内容，再在 AI 面板连接源页 Agent、Codex 或 Qoder，或复制可直接执行的任务。
3. **审阅 AI 修改。** 源页核对并独立保留返回的完整 HTML，再并排展示修改前后，把不同变化直接标在页面上。
4. **决定当前使用哪一版。** 点击“查看修改”后，满意就选择“采用修改”，不满意就选择“不用这次”继续；任何一侧都不会被静默覆盖。

### 源码优先，而不是 DOM 优先

```text
真实 HTML
  → 原生 DOM / Selection / IME 操作意图
  → SourceIndex + TargetResolver 精确定位
  → 最小 SourcePatch
  → Hash 校验后的原子文件写回
```

真实 HTML 字节始终是唯一事实源，预览 DOM 只是可丢弃的投影，永远不会被序列化回源文件。源页不是低代码搭建器；目标不明确或无法安全修改时，系统会停止而不是猜测。

## Authorized source development / 授权源码开发

Stemmio is an Electron desktop application built with React and TypeScript. This private repository includes the renderer, desktop boundary, source-patch engine, validation protocol, fixtures, automated gates, and release provenance tooling.

源页是使用 React、TypeScript 与 Electron 构建的桌面应用。本私有仓库包含渲染界面、桌面权限边界、源码 Patch 引擎、校验协议、固定样本、自动化门禁和发布溯源工具。

### Internal local development / 内部本地开发

Requires macOS 12 or later and Node.js `22.13.0` or a compatible Node 22 release.

需要 macOS 12 或更高版本，以及 Node.js `22.13.0` 或兼容的 Node 22 版本。

```bash
git clone https://github.com/Charleyli925/Stemmio.git
cd Stemmio
npm ci
npx playwright install chromium
npm run desktop:dev
```

### Validation / 验证

```bash
npm run task:status        # inspect branch, diff, and worktree
npm run task:start -- fix/short-name
npm run gate:edit          # focused feedback while editing
npm run task:finish        # completed task gate against origin/main
npm run gate:release:auto  # full clean-source release gate
npm run release:mac        # build and verify the arm64 DMG
```

Release and artifact gates accept only committed, clean source trees. See the [development guide](docs/DEVELOPMENT.md), [test strategy](tests/TEST_STRATEGY.md), [usage telemetry operations](docs/USAGE_TELEMETRY.md), and [release guide](docs/RELEASING.md).

发布与安装包门禁只接受已经提交且工作区干净的源码。详见[开发指南](docs/DEVELOPMENT.md)、[测试策略](tests/TEST_STRATEGY.md)、[使用数据运维说明](docs/USAGE_TELEMETRY.md)和[发布指南](docs/RELEASING.md)。
