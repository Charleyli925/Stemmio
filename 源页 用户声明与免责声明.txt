源页（Stemmio）用户声明与免责声明

更新日期：2026 年 9 月 2 日

一、产品定位

源页是一个本地 HTML 编辑器与 AI Agent 协作工具，不提供 AI 模型服务，也不替代法律、医疗、财务或其他专业意见。

二、AI 内容

AI Agent 生成或修改的内容可能不准确、不完整、不适用，或包含安全与合规风险。请在采用、发布或交付前自行审阅、测试并保留必要备份。是否使用 AI 结果及由此产生的后果，由用户自行判断和承担。

三、本地数据与第三方服务

源页不会在未经用户选择时把项目内容交给第三方 AI 服务。每次发送前，用户可以选择“源页 Agent”“Qoder CLI”“Codex”或“复制任务”。选择源页 Agent 后，用户在设置中填入所选厂商的 API Token；源页只把本轮冻结的 HTML、评论、附件和项目规则发给该厂商的 HTTPS 接口，模型不获得本机文件系统或终端权限，Token 只保留在本次会话内存中。选择 Qoder CLI 后，源页会启动用户本机独立安装的 Qoder CLI，由 Qoder 按本轮冻结任务读取 HTML、评论、附件、项目规则、Request 内本机文件路径，以及 Qoder 账号或会话所需元数据，并可能通过 Qoder 服务处理这些内容。选择 Codex 后，源页会为本轮启动用户本机独立安装的 Codex ACP；Codex 修改时可能以当前用户的读取权限访问这台 Mac 上的其他本机文件，并将完成任务所需的冻结资料、本机文件内容、路径及账号或会话元数据发送至 Codex 服务。选择复制时，只有用户主动粘贴或发送后，内容才会进入相应的第三方服务。

Qoder CLI 与 Codex ACP 以当前本机用户权限运行。源页会限制它们通过 ACP 请求的文件和命令范围，但这些限制不构成对本机读取权限的完整操作系统隔离。源页 Agent 由 Stemmio 中介全部文件读写。所有 Agent 的结果都先进入候选审阅，只有用户明确采纳后才成为正式版本。选择自动执行表示用户信任所选 Agent 处理本轮资料。

第三方服务如何处理数据，适用其各自的服务条款与隐私政策。请勿提交无权分享、受保密义务约束或不应由第三方处理的内容。

四、使用与故障数据

为帮助改进源页的功能与稳定性，桌面应用默认回传有限的、使用随机安装标识关联的产品使用与故障统计，包括功能模块与项目流程的使用情况、编辑与保存结果、提醒的展示与操作、中断情况、稳定错误码以及应用版本和系统架构。

这些 Stemmio 产品遥测不会包含 HTML 内容、评论内容、附件内容或名称、剪贴板内容、文件名、文件路径、提示词、原始错误文本或错误堆栈；源页也不会读取或使用电脑序列号、设备名、Apple 账号等直接身份信息。项目仅以本机随机密钥生成的不可逆标识参与统计，不能由回传数据还原项目名称或路径。这里的遥测边界不限制上一节中用户主动选择的 Qoder 或其他第三方 Agent 数据处理。

应用首次运行时会随机生成独立安装标识，数据发送至 PostHog US Cloud。网络服务在传输过程中可能按其正常运行机制接触来源 IP，但源页不会把 IP 写入事件字段，并要求 PostHog 不建立人员画像或保存地理位置属性。完整边界请参阅安装包内随附的 PRIVACY.md。

五、本地文件

源页会直接读取和修改用户选择的本地 HTML 文件。虽然产品提供源码校验、自动写回和版本保留机制，仍建议对重要文件另行备份，并在接受 AI 修改前核对最终内容。
